# Product Scene Remix

一个通用的开源 Agent Skill：首次建立用户自己的产品身份档案，以后只需上传场景参考图，即可自动替换画面中的全部原产品、检查结果并保存成品。

无论生成一张还是多张图片，每张成品都会在保持核心场景逻辑的同时，对非主体装饰、陈列细节、光线、裁切或背景等至少两类次要元素进行差异化调整；仅替换产品不算完成二创。

版本 1.2.0 新增“主体产品身份锁定”：产品的外形、比例、材质、颜色、标签、瓶盖及附件结构均不得被差异化规则改动；所有二创差异只允许发生在非主体装饰、道具、陈列、灯光、裁切和背景等场景元素。产品数量或位置仅能因真实尺寸无法容纳或用户明确要求而做最小调整，且不计入差异化。

## 一句话安装

在支持从 GitHub 安装 Agent Skills 的客户端中发送：

> 帮我安装这个 Skill：https://github.com/RZ866/product-scene-remix

安装完成后发送：

> 开始使用

也可以直接上传参考场景图并说“替换成我的产品”。如果尚未建档，Skill 会自动进入一次性初始化。

## 初始化内容

1. 上传每款产品清晰、完整的白底图。
2. 自动建立产品身份档案。
3. 设置一次默认图片保存位置。
4. 后续仅上传参考场景图，无需重复上传产品图。

## 兼容性

本仓库遵循通用 `SKILL.md` 目录结构。完整工作流要求宿主具备：图片输入、图片生成或编辑、持久化文件读写能力。具体安装方式和所用图片模型由宿主平台决定。

## Privacy

产品图片、身份档案和生成结果保存在用户自己的环境中，不属于本仓库内容。提交问题或贡献代码前，请勿上传私人产品素材、配置文件或生成结果。
